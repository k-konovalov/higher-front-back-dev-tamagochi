# Dislaimer

В этом проекте используется LLM qwen 3.8 27B / Alice AI / Gigachat. В 2026 глупо не использовать LLM для решения задач. Но LLM не должна заменять компетенции.

## LLM помогает с

- ассистивное составление плана и декомпозиция
- объяснение дальнейших шагов через наводящие вопросы или при затыках
- ревью написанных решений
- написание docstring и unit-тестов

## LLM не помогает

- не заменяет человека на всем проекте под ключ
- с непосредственным написанием кода
