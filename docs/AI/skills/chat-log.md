# Логирование диалога «вопрос-ответ»

> Скилл для сохранения истории общения между пользователем и ИИ-тьютором. После каждой сессии создаются два файла: краткий пересказ и машиночитаемый лог.

## Роль

Ты ведёшь **лог диалога** между пользователем и ИИ-тьютором. После каждой сессии обучения/тьюторства ты сохраняешь:

1. **`NN-summary.md`** — краткий пересказ общения (для человека).
2. **`NN-chat.json`** — машиночитаемый лог в формате 1-1 (как при экспорте чата).

Это позволяет отслеживать прогресс студента, возвращаться к прошлым сессиям и анализировать, какие темы были затронуты.

## Место хранения

Логи сохраняются в директорию [`docs/AI/ai_logs/`](../ai_logs/).

## Нумерация файлов

Используется **простой инкремент**:

- Первая сессия: `00-summary.md`, `00-chat.json`
- Вторая сессия: `01-summary.md`, `01-chat.json`
- Третья сессия: `02-summary.md`, `02-chat.json`
- и так далее.

Номер — двузначное число с ведущим нулём (`00`, `01`, ..., `99`). Перед созданием новой сессии определи следующий номер, посмотрев на максимальный существующий номер в `docs/AI/ai_logs/`.

## Формат `NN-summary.md`

Краткий пересказ общения для человека. Структура:

```markdown
# Сессия NN — <дата>

## Тема
<краткое описание темы сессии>

## Вопросы пользователя
- <вопрос 1>
- <вопрос 2>
- ...

## Ответы/советы тьютора
- <ключевой совет 1>
- <ключевой совет 2>
- ...

## Прогресс
<что студент понял / что сделал / что осталось>

## Следующие шаги
<что делать дальше>
```

## Формат `NN-chat.json`

Машиночитаемый лог в формате 1-1 (как при экспорте чата). Каждое сообщение — объект с полями `role` и `content`:

```json
{
  "session": 0,
  "date": "2026-10-15T18:00:00+03:00",
  "messages": [
    {
      "role": "user",
      "content": "Я не знаю, с чего начать."
    },
    {
      "role": "assistant",
      "content": "Давай разобьём задачу на части. Какие три класса нужно написать?"
    },
    {
      "role": "user",
      "content": "AbstractTamagochi, AbstractClicker и AbstractGame."
    }
  ]
}
```

### Поля

- `session` — номер сессии (целое число, совпадает с `NN` в имени файла).
- `date` — дата/время сессии в ISO 8601.
- `messages` — массив сообщений в хронологическом порядке.
  - `role` — `"user"` (пользователь) или `"assistant"` (ИИ-тьютор).
  - `content` — текст сообщения.

## Когда логировать

- После **каждой** сессии тьюторства/обучения.
- В конце сессии, когда диалог завершён или достигнута естественная пауза.
- Если сессия прервана — всё равно сохрани лог с тем, что было.

## Как определить следующий номер

1. Посмотри содержимое `docs/AI/ai_logs/`.
2. Найди максимальный номер `NN` среди существующих файлов.
3. Следующий номер = максимальный + 1 (с ведущим нулём).

Пример: если есть `00-*` и `01-*`, следующая сессия — `02-*`.
